プライバシーポリシー

ナンバーズ4予想AI 忍者 ナンバーズ3予想AI KUNOICHI

開発者「Hazimekom」が提供するアプリ「ナンバーズ4予想AI 忍者」および「ナンバーズ3予想AI KUNOICHI」（以下、総称して「本アプリ」）は、ユーザーのプライバシーを尊重し、以下の方針に基づいて個人情報を取り扱います。

1. 取得する情報および利用目的

本アプリでは、サービスの提供・改善および広告配信のため、以下の第三者提供ツールを利用して情報を自動取得します。取得される情報は匿名化されており、特定の個人を識別するものではありません。

  • Google Analytics for Firebase（利用状況分析）
    取得情報：アプリの起動回数、特定の機能（予測ロジック等）の使用頻度、端末のモデル、OSバージョン。
    利用目的：アプリの利便性向上および利用状況の統計的把握。
  • Firebase Crashlytics（クラッシュ報告）
    取得情報：アプリがクラッシュした際のスタックトレースおよび端末の状態情報。
    利用目的：不具合の迅速な特定および修正、品質向上。
  • Firebase Cloud Messaging / Remote Config（通知・設定管理）
    取得情報：プッシュ通知用トークン、アプリの設定値。
    利用目的：最新の更新情報やイベント情報の配信、アプリ動作の動的最適化。
  • Google AdMob（広告配信）
    取得情報：広告識別子（AD ID）、広告へのインタラクション情報。
    利用目的：広告の配信最適化および不正防止。

2. 権限に関する明示（重要）

本アプリは、ユーザーのプライバシー保護と透明性を重視し、以下の権限を一切使用しません。

  • 電話番号や通話状態の読み取り（READ_PHONE_STATE）
  • 端末内の写真、メディア、ファイルへのアクセス（READ/WRITE_EXTERNAL_STORAGE）

3. 情報の保存とセキュリティ

  • ユーザーが入力したデータや予測履歴は、原則として端末内（ローカル）に保存されます。
  • データのバックアップ・共有機能を利用する際も、本アプリがユーザーの認証情報やファイルの中身を直接取得・保持することはありません。
  • 取得されたデータは、Google社の安全なサーバーで暗号化されて管理されます。

4. ユーザーのコントロール権

ユーザーは、端末の設定より以下の操作が可能です。

  • 広告識別子のリセットおよびパーソナライズド広告の無効化
  • プッシュ通知の受信設定（ON/OFF）の変更
